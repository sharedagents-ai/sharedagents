# Support

Start with the [installation guide](docs/getting-started/installation.md),
[configuration guide](docs/getting-started/configuration.md), and
[troubleshooting guide](docs/guides/troubleshooting.md).

## Questions and help

Use [GitHub Discussions](https://github.com/sharedagents-ai/sharedagents/discussions)
for setup questions and design conversations. Include the installed version,
OS, Python version, installation method, optional extras, and a small
reproduction. Community support has no guaranteed response time.

## Bugs and feature requests

Search existing issues first. Use the
[issue templates](https://github.com/sharedagents-ai/sharedagents/issues/new/choose)
for a reproducible bug or a concrete feature proposal. Explain the observed
behavior and expected result, and describe any workaround.

Before posting, remove secrets, personal identities, private host names,
addresses, phone numbers, conversation content, and account IDs from excerpts
and screenshots. Do not attach a runtime home, environment file, authentication
database, pairing QR code, or raw session ledger.

## Security and conduct

Report security vulnerabilities through the private channel in
[SECURITY.md](SECURITY.md). Report conduct concerns using
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Public issues are not the right place
for either sensitive report.
