Artificial Analysis API key required

  1. Create a free key on the Artificial Analysis login page (Free tier, internal use with attribution).
  2. Append it to the operator env file, then reload this tab: echo 'ARTIFICIAL_ANALYSIS_API_KEY=your-key-here' >> ~/.sharedagents/.env

The web server resolves the key from its own environment, ~/.sharedagents/.env, or /etc/environment. The key is never sent to the browser and never written by this page.
