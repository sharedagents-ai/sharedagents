Schedule the prompt to run on its own — in a new conversation or one you already have.

A loop step is one scheduled turn: the prompt runs in the bound conversation with the loop guide attached. If the conversation is busy when a tick fires, that run is skipped and counted as a miss — runs never queue up. Three failed runs in a row pause the loop automatically.
